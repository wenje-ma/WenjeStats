## 背景信息

图 2.5 左图展示了一维输入下,相关函数取 $R(x)=e^{-x^{2}/\theta^{2}}$ 且 $\theta=0.08$ 时,高斯过程的若干条样本路径.假设我们对函数采样得到观测数据,如图中蓝色圆点所示(图 2.5 中图),本章核心目标是求解给定数据后函数的后验分布;图 2.5 右图同样绘制了 $\theta=0.08$ 条件下该后验高斯过程的若干样本路径.可以观察到所有样本路径均穿过观测数据点,且相较于先验分布,函数 $h(\boldsymbol{x})$ 的整体不确定性大幅降低.

## 指令

令画布宽 15 英寸,高 5 英寸,将画布分为 1x3:

```r
options(repr.plot.width=15,repr.plot.height=5)
par(mfrow=c(1,3))
```

定义函数 $f(x)=\frac{10\pi x}{1+64(x-.25)^{2}}+x^{2}$,在 $[0,1]$ 上取 301 个点用于绘制图像,计算其对应的真实函数值;再等距取 10 个观测点,计算其对应的观测值:

```r
f=function(x) sin(10*pi*x)/(1+64*(x-.25)^2)+x^2
N=301
test=seq(0,1,length=N)
true=f(test)
n=10
D=((1:n)-1)/(n-1)
y=f(D)
```

令参数 $\theta=0.08$,计算 $\boldsymbol{R}$,$\boldsymbol{R}^{-1}$,$\boldsymbol{r}(\boldsymbol{x})'$ 与 $\boldsymbol{r}(\boldsymbol{x})'\boldsymbol{R}^{-1}$:依据 $\widehat{\mu}=\frac{\boldsymbol{1}'\boldsymbol{R}^{-1}\boldsymbol{y}}{\boldsymbol{1}'\boldsymbol{R}^{-1}\boldsymbol{1}}$(广义一阶矩,广义最小二乘)计算 $\widehat{\mu}$;依据 $\tau^{2}=\frac{1}{n-1}\cdot(\boldsymbol{y}-\widehat{\mu}\boldsymbol{1})'\boldsymbol{R}^{-1}(\boldsymbol{y}-\widehat{\mu}\boldsymbol{1})$ 计算 $\tau^{2}$:

```r
theta=.08
R=exp(-(outer(D,D,"-")/theta)^2)
Rinv=solve(R)
R_pred=exp(-(outer(test,D,"-")/theta)^2)
one=rep(1,n)
mu_hat=as.numeric((t(one)%*%Rinv%*%y)/(t(one)%*%Rinv%*%one))
e=y-mu_hat
tau2_hat=as.numeric(t(e)%*%Rinv%*%e/(n-1))
pred=as.numeric(mu_hat+R_pred%*%Rinv%*%e)
```

已知真实的函数 $h(\boldsymbol{x})\sim\mathrm{GP}(\mu(\boldsymbol{x}),K(\boldsymbol{x},\cdot))$,因此依据公式 $K(\boldsymbol{x},\boldsymbol{u})=\tau^{2}R(\boldsymbol{x}-\boldsymbol{u})$,还需要求解 $R(\boldsymbol{x}-\boldsymbol{u})$:

```r
S0=exp(-(outer(test,test,"-")/theta)^2)
```

开始先验:使用 `MASS` 包中的 `mvrnorm` 函数从均值为 $0$,方差为 $\tau^{2}R(\boldsymbol{x}-\boldsymbol{u})$ 的高斯过程中任意抽取 5 条曲线作为先验示例:

```r
set.seed(1)
library(MASS)
u=mvrnorm(n=5,mu=rep(0,N),Sigma=tau2_hat*S0)
```

开始作图:左图:一次性绘制多条图像,其中曲线类型为实线,$x$ 轴上标注为 `x`,$y$ 轴上标注为 `y`,颜色使用 2-6,线宽为 3,$y$ 轴显示范围为 $[\min(f(x))-.25,\max(f(x))+.25]$,主标题为"prior distribution",标题缩放系数为 3,坐标轴缩放系数为 2,轴标签缩放系数为 2;叠加真实函数图像,其中曲线类型为实线,线宽为 4:

```r
matplot(test,t(u),type="l",xlab="x",ylab="y",col=2:6,lwd=3,ylim=c(min(true)-.25,max(true)+.25),main="prior distribution",cex.main=3,cex.axis=2,cex.lab=2)
lines(test,true,type="l",lwd=4)
```

中图:与左图相同,只是主标题换成"data";叠加观测点,其中点的类型为实心圆点,放缩系数为 4,颜色为蓝色:

```r
matplot(test,t(u),type="l",xlab="x",ylab="y",col=2:6,lwd=3,ylim=c(min(true)-.25,max(true)+.25),main="data",cex.main=3,cex.axis=2,cex.lab=2)
lines(test,true,type="l",lwd=4)
points(cbind(D,y),pch=16,cex=4,col="blue")
```

依据公式 $h(\boldsymbol{x})\mid\boldsymbol{y}\sim\mathrm{GP}(\mu+\boldsymbol{r}(\boldsymbol{x})'\boldsymbol{R}^{-1}(\boldsymbol{y}-\mu\boldsymbol{1}),\tau^{2}(R(\boldsymbol{x}-\cdot)-\boldsymbol{r}(\boldsymbol{x})'\boldsymbol{R}^{-1}\boldsymbol{r}(\cdot)))$,其中均值在克里金部分已算毕;还需计算方差部分:

```r
S=tau2_hat*(S0-R_pred%*%Rinv%*%t(R_pred))
```

开始后验:从均值为 $\mu+\boldsymbol{r}(\boldsymbol{x})'\boldsymbol{R}^{-1}(\boldsymbol{y}-\mu\boldsymbol{1})$,方差为 $\tau^{2}(R(\boldsymbol{x}-\cdot)-\boldsymbol{r}(\boldsymbol{x})'\boldsymbol{R}^{-1}\boldsymbol{r}(\cdot))$ 的高斯过程中任意抽取 5 条曲线作为后验示例:

```r
set.seed(1)
u=mvrnorm(n=5,mu=pred,Sigma=S)
```

右图:与中图一致,只是主标题改为"posterior distribution":

```r
matplot(test,t(u),type="l",xlab="x",ylab="y",col=2:6,lwd=3,ylim=c(min(true)-.25,max(true)+.25),main="posterior distribution",cex.main=3,cex.axis=2,cex.lab=2)
lines(test,true,type="l",lwd=4)
points(cbind(D,y),pch=16,cex=4,col="blue")
```
